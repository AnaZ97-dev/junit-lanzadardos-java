Pruebas Unitarias con JUnit en Java (LanzaDardos)
Proyecto de práctica de Entornos de Desarrollo enfocado en la creación y ejecución de pruebas unitarias utilizando JUnit en un entorno de Java.

Tecnologías y Herramientas
Lenguaje: Java (JDK 17)
Framework de pruebas: JUnit
IDE: Apache NetBeans 23
Sistema de construcción: Apache Ant

Funcionalidades y Conceptos Aplicados
Clase principal (LanzaDardos): Implementación de una clase con métodos para cargar y descargar dardos, controlando que las cantidades no sean negativas ni cero.
Pruebas Unitarias (MainTest): Creación de una batería de tests (testCargarValido, testDescargarValido, testCargarNoValidoCero, testDescargarNoValidoNegativo) para verificar el correcto funcionamiento de la lógica.
Ejecución de Tests: Uso de la integración de NetBeans con JUnit para ejecutar las pruebas y comprobar si el código pasa las validaciones.

Cómo ejecutar el proyecto
Abre el proyecto en Apache NetBeans.
Haz clic derecho sobre el proyecto y selecciona "Test" para ejecutar todas las pruebas unitarias.
Revisa la ventana de resultados de NetBeans para ver qué tests han pasado y cuáles han fallado.
